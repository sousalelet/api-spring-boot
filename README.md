# API de Livros

Projeto desenvolvido em Java com Spring Boot para cadastro e listagem de livros.

## Funcionalidades

- Cadastro de livros (POST /livros)
- Listagem de livros (GET /livros)

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA

## Como executar

1. Clonar o repositório:
git clone https://github.com/seu-usuario/seu-repositorio.git

2. Abrir o projeto em uma IDE (IntelliJ ou VS Code)

3. Executar a aplicação

## Observação

Projeto desenvolvido para prática de APIs REST e versionamento com Git e GitHub.
